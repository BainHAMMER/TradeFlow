# TradeFlow — Архитектура и описание аддона

## 1. Концепция
**`TradeFlow`** объединяет в одном быстром, не лагающем окне для **WoW Forever (`Interface: 16001`)**:
- **Полноценное окно профессий и умную DAG-очередь в стиле Skillet** (без его багов и тормозов на `BAG_UPDATE`),
- **Калькулятор шанса скиллапа и расчёта маршрута прокачки в стиле SkillUp Forever**,
- **Отображение реальных предметов и заклинаний по их ID напрямую из клиента игры** (без кривых статических переводов названий предметов),
- **Прямую интеграцию с Auctionator (`Auctionator.API.v1`) и кнопкой «Докупить по списку» у торговцев**.

## 3. Ключевые особенности реализации

1. **Реальные предметы из клиента по ID (`Core/Core.lua`):**
   - `ns:GetItemDisplay(itemID)` и `ns:GetRecipeDisplay(recipeID)` запрашивают название, иконку, цвет качества и `itemLink` напрямую у клиента (`C_Item.GetItemInfo`, `C_Item.GetItemNameByID`, `C_Item.RequestLoadItemDataByID`) и автоматически обновляют UI по `GET_ITEM_INFO_RECEIVED` / `ITEM_DATA_LOAD_RESULT`.
   - Наведение мыши вызывает нативный `GameTooltip:SetItemByID(itemID)` / `SetSpellByID(recipeID)`, `Shift+клик` вставляет реальную ссылку предмета в чат или ищет его на аукционе, `Ctrl+клик` открывает примерочную.
2. **Мгновенный пересчёт крафтов (`Core/Inventory.lua`):**
   - Дебаунс `BAG_UPDATE_DELAYED` (`0.08` с) и кэширование результатов по ревизии инвентаря `ns.invRev`.
   - На каждой строке рецепта отображается `[в сумках / +с учётом крафта реагентов / +с вендором]`.
3. **Умная DAG-очередь без багов Skillet (`Core/Queue.lua`):**
   - При добавлении рецепта рекурсивно разворачивает недостающие полуфабрикаты (в том числе из **второй профессии персонажа**) и выстраивает их строго перед рецептом-потребителем.
   - `GetShoppingList()` вычитает промежуточные выходы ранних шагов очереди, поэтому в список покупок попадают только реально недостающие базовые материалы с разбивкой `Сумки | Банк | Альты`.
   - `ProcessQueue()` не затирает заказанное количество при частичном крафте и уменьшает счётчик строго по факту `UNIT_SPELLCAST_SUCCEEDED`.
4. **Интеграция с Auctionator и вендорами (`UI/VendorAuction.lua`):**
   - Автоматически поддерживает список закупок `"TradeFlow: <Имя>"` в Auctionator (`ConvertToSearchString` + `CreateShoppingList` / `DeleteShoppingList`), а кнопка **«Найти на AH»** запускает `MultiSearchAdvanced` с точными количествами.
   - При открытии торговца (`MERCHANT_SHOW`) над окном появляется панель с кнопкой **«Докупить по списку»**.
